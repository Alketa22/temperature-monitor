# temperature-monitor
A simple C++ program that checks temperature reading and shows alerts when the values are entered by the user
## What it does
Ask the user to enter a temperature value in celsius degrees
Prints "ALERT, too hot" if the tempeature is above 30 degrees celsius
Prints "Too cold"if temperature is under 10 degrees celsius

## What l practiced in this program
Variables, input and output, if else conditions, while loop
